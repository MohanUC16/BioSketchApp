# Assignment Deliverables

## Included in this project

1. `App.js` — complete React Native BioSketch screen.
2. `assets/profile.png` — local profile image asset extracted from the supplied reference image.
3. `app.json` — Expo project metadata and assignment description.
4. `package.json` — Expo dependencies and run commands.
5. `README.md` — setup, Snack, naming, and sharing instructions.

## User-authenticated steps

Expo Snack saving and share-link generation require the student's Expo account, so those steps must be completed in the Snack web editor:

1. Open https://snack.expo.dev/.
2. Create or open a Snack and replace `App.js` with this project's `App.js`.
3. Upload `assets/profile.png` in the Snack Assets panel.
4. Save as `Hands-On Assignment 2 _Lastname`.
5. Set description to `My BioSketch @ UC`.
6. Copy the generated Snack share link.
7. Run the Snack on Web, Android, and iOS and capture the three required screenshots.
