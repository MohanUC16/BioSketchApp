# Hands-On Assignment 2 - UC BioSketch

This standalone Expo/React Native application displays a University of the Cumberlands bio sketch using a local professional portrait asset.

## Requirements covered

- React Native / Expo app structure
- UC welcome message
- `Course ID: MSCS 533` on the next line
- Bio sketch text
- Required code comment in `App.js`
- Red `#e60026` background
- Local portrait in `assets/profile.png`
- Web, Android, and iOS-compatible React Native layout
- Expo metadata:
  - Name: `Hands-On Assignment 2 - Biosketch`
  - Description: `My BioSketch @ UC`

## Run locally

Install Node.js LTS, then run:

```bash
npm install
npx expo start
```

Use Expo's web, Android, or iOS launch options. For Snack, create a new Snack at https://snack.expo.dev/, replace `App.js`, and upload `assets/profile.png`.

## Save and share in Expo Snack

Sign in to Expo, save the Snack as:

```text
Hands-On Assignment 2 _Lastname
```

Set its description to:

```text
My BioSketch @ UC
```

Then copy the generated Snack share link into the assignment document.

Screenshots are intentionally not generated by this deliverable; capture the Web, Android, and iOS simulator views after publishing the Snack.
